# Circular Single Linked List

Lengkapi:

```text
SisipDataDiAkhir()
hapusSatuDataDiAwal()
hapusSatuDataDiAkhir()
```

---

# Circular Double Linked List

Lengkapi:

```text
SisipDataDiAkhir()
hapusData()
```

---

# Pengujian

Tambahkan pemanggilan method pada:

```java
main()
```

kemudian jalankan program untuk memastikan hubungan circular tetap benar.

Circular Single Linked List:

```text
pAkhir.setelah == pAwal
```

Circular Double Linked List:

```text
pAkhir.setelah == pAwal
pAwal.sebelum == pAkhir
```
